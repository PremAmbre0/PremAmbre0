## 🧠 What I work on

- **System architecture** and core platform services
- **Cloud infrastructure** and delivery on GCP and Firebase, with CI/CD
- **Event-driven services**, queues and the contracts between them
- **Multi-tenant platforms** and white-label design systems
- **Security by design**: authorization at the server, approval workflows, audit trails
- **LLM integration** with Claude and Gemini: tool use, streaming, offering tools by intent, and server-side gateways that keep API keys out of the browser
- **Frontend architecture** and performance, built by someone who started there

Since 2022 I've gone from leading frontend architecture to owning systems end to end, mentoring developers along the way.
